# Naming — this repo is part of a LACS

This codebase (Buddy) is a **Lateral Autonomous Cognition System (LACS)** — the
term used here instead of "AGI."

"LAC" is overloaded: it has been used for the whole system, for the sellable
memory kit, and for the roam-learning loop. Don't reinvent the vocabulary in
this repo. The single source of truth for system-vs-organ naming — 14-Tier
Memory, Kokoro Heart-Map, tokenizer×4, Roam-Learning Loop, … — is:

→ **`corpus-ai/LACS.md`**

Rule of thumb: the *system* is **LACS**; each *organ* has its own name; **"LAC"
alone is retired** as ambiguous.
